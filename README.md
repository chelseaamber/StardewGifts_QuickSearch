# 🎁 Stardew Gifts - Simple Quick Search
For when you happen to stroll past a villager and want to check if they would appreciate that random item you have in your inventory. 

The tool allows you to input a villager and name of the item. It will tell you whether the gift is loved, liked, neutral or hated. 

I've seen a few gift guide / cheat sheets that include a lot of information that still involves having to look amongst many other items for whether this item okay to gift. I wanted to create this tool for searching the exact villager and item you are thinking of gifting - nothing more nothing less!

I also have one monitor, and don't enjoy having to tab out of the game to search / having to navigate the stardew wiki on my phone. The interface is simple and straightforward, making it really easy to have up on your phone nearby for quick searching.
